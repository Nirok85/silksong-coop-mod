# План улучшения проекта (2026-11)

Документ фиксирует phased-план после релиза v3.0.3. Он дополняет исторический
список из `ROADMAP.md` и служит основой для следующих релизов.

**Принципы**

- Стабильность важнее количества фич: лучше меньше рассинхронов, чем больше
  экзотических возможностей.
- Любое изменение протокола — только через повышение `NetworkProtocol.Version`
  или обратно совместимый feature flag.
- Каждая фаза заканчивается сборкой с `TreatWarningsAsErrors`, зелёными тестами
  и ручным smoke-тестом (UDP + Steam), если затронут сетевой путь.
- Существующие тестовые файлы не переписываются; новое покрытие добавляется
  отдельными файлами.

## Ближайший релиз

**v3.2.0** — синхронизация мира и бой: фазы боссов, polling persistent-объектов,
стабильный ключ дропов, кросс-сценовый revive с bench-fallback. Плюс весь UX из
3.1.0 (локализация, F10/F11, onboarding). Протокол не менялся (v8); для
дедупликации дропов по persistent ID обе стороны должны быть на 3.2.0.
