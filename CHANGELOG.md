# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/),
и этот проект придерживается [Semantic Versioning](https://semver.org/).

## [2.0.6] - 2026-10-27

### Изменено
- **Реструктуризация кода (Фазы 1–2):**
  - Добавлены `#region` блоки во все 26 файлов >200 строк (поля, свойства, Unity lifecycle, методы)
  - Добавлена XML-документация ~285+ публичным API (классы, интерфейсы, методы)
  - Исправлены 4 неуместных null-forgiving оператора (`!`)
  - Стандартизировано логирование (единый паттерн `SilksongCoopPlugin.LogWarn`)

## [2.0.5] - 2026-10-27

### Исправлено
- **Невидимый клон игрока 2**: `tk2dSprite` создавался через `AddComponent<>()`, что не создаёт рендерер в 2D Toolkit. Теперь используется `tk2dSprite.AddComponent(go, collection, spriteId)` — MeshFilter + MeshRenderer + меш создаются автоматически
- **Игрок 2 не синий**: `PaletteSwapController` применяет HueShift к корректному рендереру tk2dSprite

## [2.0.4] - 2026-10-27

### Исправлено
- **Жёлтое свечение клона**: удалён «голый» MeshRenderer/MeshFilter без меша, рендеривший неинициализированную геометрию
- **Постоянно включённый RimLight**: `AdaptiveRimLight` теперь выключен по умолчанию, включается только во время рывка
- **Sorting layer**: синхронизация через рендерер tk2dSprite вместо голого MeshRenderer

## [2.0.3] - 2026-10-27

### Добавлено
- Диагностическое логирование F10/F11: определение работающей системы ввода (Legacy Input vs New Input System), одноразовая проверка Update()

### Исправлено
- **Spectator mode**: отключение коллайдеров при входе, восстановление при выходе; новый метод `ExitSpectatorMode()`
- **Синхронизация валюты**: расчёт дельты от текущего количества вместо абсолютного значения (устранение десинка)

## [2.0.2] - 2026-10-27

### Изменено
- Удалены отладочные `Debug.Log` из `CoopMenuUI`
- Исправлена двойная отправка `OnPeerConnected` в `MockNetworkTransport.CreatePair()`
- Улучшены комментарии packet ordering логики (семантика 10-секундного порога clock-wrap)

## [2.0.1] - 2026-10-26

### Исправлено
- **DiagnosticsOverlay (F11)**: полностью переписан компонент отрисовки оверлея
  - Устранена утечка памяти: `Texture2D` больше не создаётся каждый кадр (кэшируются статически)
  - Исправлена невидимость оверлея: тёмный полупрозрачный фон корректно отрисовывается через `GUI.DrawTexture`
  - Удалён `GUIUtility.RotateAroundPivot`, ломавший весь последующий GUI-рендер
  - Добавлено сохранение/восстановление `GUI.matrix` и `GUI.color` в блоке `try/finally`
  - Добавлены видимые границы, сетка и цветные метки осей
  - Добавлена строка статистики сессии (длительность, пакеты in/out)
- **KeybindManager**: устранён краш `InvalidOperationException` («Collection was modified») при итерации по словарю биндов — итерация по снимку списка

### Известные проблемы
- `NetworkDiagnostics.RecordPing()` не вызывается из транспорта — график ping остаётся пустым. Исправлено в v2.1.0 (см. ROADMAP).

## [2.0.0] - 2026-10-26

### Добавлено
- **Система безопасности сетевых соединений:**
  - Валидация пакетов с проверкой диапазонов значений полей
  - Rate limiter для предотвращения DoS-атак (token bucket алгоритм)
  - Challenge-response аутентификация для защиты от несанкционированного доступа
  - Пометка устаревших 8-символьных кодов комнат как небезопасных

- **Панель настроек в игре:**
  - Настраиваемые горячие клавиши (F9, F10, F11)
  - Пресеты качества (Low/Medium/High/Custom)
  - Сохранение настроек через BepInEx конфигурацию

- **Расширенная диагностика:**
  - Оверлей диагностики с графиками в реальном времени (F11)
  - 60-секундная история метрик (ping, packet loss, bandwidth)
  - Экспорт диагностических данных в файл
  - Визуализация качества соединения

- **Автоматизированное интеграционное тестирование:**
  - Нагрузочный тест: 1000 пакетов/сек в течение 60 секунд
  - Хаос-тесты с потерей пакетов 5-30%
  - Тесты стабильности при быстром переподключении
  - Тесты на утечки памяти при длительной работе

### Изменено
- **Архитектура:**
  - Декомпозиция SilksongCoopPlugin (god object) на специализированные сервисы
  - Замена статических глобальных переменных на скоуп-контекст (RemoteApplyScope)
  - Устранение всех предупреждений nullable-reference (CS8602)

- **Сетевой слой:**
  - Устранение реентерабельности блокировок в LiteNetLibTransport
  - Улучшение надежности транспорта
  - Интеграция валидации пакетов в процесс обработки

- **Пользовательский интерфейс:**
  - Интеграция KeybindManager и QualityPresetManager в CoopMenuUI
  - Расширение NetworkDiagnostics для хранения исторических данных
  - Добавление DiagnosticsOverlay для визуализации метрик

### Безопасность
- Защита от подделки пакетов с помощью HMAC-SHA256
- Ограничение скорости отправки пакетов (предотвращение флуда)
- Валидация всех входящих данных перед обработкой
- Отключение устаревших методов кодирования комнат (8 символов)

### Тестирование
- Добавлено 4 новых интеграционных теста
- Общее количество тестов увеличено с 603 до 607
- Все тесты проходят успешно (100% pass rate)
- Время выполнения тестов: ~3.9 секунды

### Технические детали
- Сборка: 0 ошибок, 0 предупреждений
- Добавлены новые модули:
  - `ConnectionAuthenticator.cs`
  - `RateLimiter.cs`
  - `PacketValidator.cs`
  - `KeybindManager.cs`
  - `QualityPresetManager.cs`
  - `DiagnosticsOverlay.cs`
  - `IntegrationTests.cs`
